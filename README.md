# Headed — Privacy Policy

This repo hosts the public privacy policy for [Headed](https://github.com/bradryanbice/headed), a
journey-overview companion app, via GitHub Pages. Only the privacy policy lives here — the app's
source and internal docs stay in the private `headed` repo.

Live page: published via GitHub Pages once enabled on this repo (Settings → Pages → source:
`main` branch, `/` root).

To update the policy, edit `index.md` and push — the source of truth is
`docs/privacy.md` in the `headed` repo; keep the two in sync.
